# Учебная практика

Навигация по заданиям. Код лежит в корне репозитория единым проектом. В папке [Учебная практика](<Учебная практика/>) у каждого подэтапа своя папка с описанием задания и ссылками на файлы, в которых оно выполнено.

## Запуск

```
mysql -u root -p < db/01_schema.sql
mysql -u root -p < db/02_import_data.sql
npm install
npm start           # http://localhost:3000
npm test
```
