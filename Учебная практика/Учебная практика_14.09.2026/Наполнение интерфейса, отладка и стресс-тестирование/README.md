# Наполнение интерфейса, отладка и стресс-тестирование

Учебная практика 14.09.2026, подэтап 4.

**Задание:** связать список на главной форме с данными из БД, показать контакты и рассчитанную скидку; партнёр без продаж должен получать 0% без падения приложения.

## Файлы

| Файл | Что в нём |
| --- | --- |
| [main.js](<main.js>) | Загрузка партнёров с сервера, построение карточек, поиск, сообщение об ошибке при недоступном сервере |
| [server.js](<server.js>) | `COALESCE(SUM(...), 0)` в запросе `SQL_PARTNERS`: партнёр без продаж получает объём 0 и скидку 0% |
| [demo.js](<demo.js>) | Демонстрационный тест расчёта скидки |

## Запуск

```
npm start           # затем открыть http://localhost:3000
npm run demo
```
