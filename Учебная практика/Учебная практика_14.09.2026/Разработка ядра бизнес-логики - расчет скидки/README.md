# Разработка ядра бизнес-логики (расчёт скидки)

Учебная практика 14.09.2026, подэтап 1.

**Задание:** изолированная функция расчёта индивидуальной скидки партнёра по суммарному объёму продаж и тесты граничных значений 9999, 10000, 49999, 50000, 300000 со 100% покрытием.

| Объём продаж | Скидка |
| --- | --- |
| < 10 000 | 0% |
| 10 000 – 49 999 | 5% |
| 50 000 – 299 999 | 10% |
| ≥ 300 000 | 15% |
