# Разработка формы добавления/редактирования партнёра

Учебная практика 21.09.2026, подэтап 2.

**Задание:** форма `PartnerEditWindow` с полями: наименование, тип (выпадающий список), рейтинг, адрес, ФИО директора, телефон, email; подсказки для телефона и email; комментарии только в неочевидных местах.
